# Angara

Прямой прокси-сервер для Linux с возможностями, которые будут развиваться поэтапно: HTTP, HTTPS через CONNECT, авторизация, правила доступа, управление ресурсами и кэширование HTTP.

**Статус: M00 — согласование требований и архитектуры.** Документы в этой ветке являются предложением. Язык, границы первого выпуска и эксплуатационные параметры ещё не утверждены владельцем проекта. Реализация и исполняемые тесты пока отсутствуют.

## Предложение для первого выпуска

- Один сервис для Linux; предлагаемый стек — Rust, Tokio, hyper и rustls.
- HTTP/1.1 forward proxy и TCP-туннели CONNECT для HTTPS.
- Обычный и TLS-защищённый вход к прокси.
- Локальные пользователи, Basic proxy authentication, ACL по источнику, пользователю, домену, IP и порту назначения.
- Ограничения соединений и времени ожидания, потоковая передача, журналы, systemd.
- Кэширование HTTP, parent proxy и дополнительные протоколы — последующие этапы.

HTTPS внутри CONNECT остаётся сквозным: TLS содержимого сайта завершается у клиента и сайта. TLS-вход к Angara защищает отдельно участок «клиент → прокси». Подмена сертификатов сайтов в первый выпуск не входит.

## Текущее состояние

Сначала владелец согласует M00. Затем Codex актуализирует документы и выдаёт DeepSeek исполнимое задание M01. Наличие документов, созданного PR или зелёного CI само по себе не означает согласования архитектуры.

Лицензия не выбрана. Совместимость с конфигурационным синтаксисом Squid не заявляется. Сроки и показатели производительности будут уточнены после выбора сценария использования и первых измерений.
